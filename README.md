# 快速原型技术及其应用 · 章节思考题与测验习题

依据课程 13 份课件整理的 36 道章节思考题答案 + 50 道章节测验习题（客观题），简答题答案按**可直接默写上卷子的文字段落**编写。纯静态单文件 HTML，无需后端、无需联网，双击即可使用。

- 在线使用：https://74185212.github.io/rapid-prototyping-exam-review/
- 离线使用：下载仓库根目录的 `index.html`，用浏览器打开

## 内容

### 部分一 · 章节思考题（36 题）

题库《章节思考题-2026.docx》共 6 章 36 题，答案全部来自所给课件（4 份 PDF、8 份 PPTX、1 份 PPT），每题标注课件出处。

| 题库章节 | 题数 | 主要答案来源 |
| --- | --- | --- |
| 第一章 概论 | 4 | 第一章 概论 |
| 第二章 数据处理 | 6 | 第二章 数据处理 |
| 第三章 工艺综合 | 13 | 光固化 / 叠层实体 / SLS / FDM / 三维打印 |
| 第四章 材料及设备 | 4 | 各工艺章节的材料部分 |
| 第五章 软模快速制造 | 5 | 软模 / 硬模 / 应用 |
| 第六章 应用 | 4 | 应用 / 医疗案例 / 生物打印 |

编排说明：题库章号与课件文件章号并不一一对应，答案按知识点跨课件检索；第三章原题库有两个编号「11」，文档中记为 11① / 11②，该章共 13 题；第四章第 1 题在课件中无集中条目，答案由各工艺章节的材料要求归纳而成。

答案原则是**问什么答什么**：原理写一段话、区别用文字对比，不分条编号、不列表格、不写与问题无关的延伸内容。答案中的**深红加粗**为原文重点标记。

### 部分二 · 章节测验习题（50 题）

来自 9 套章节测验，**按题型归类**，题号连续 1–50；每题一张卡，答案默认收起、可单独展开：

| 题型 | 题数 |
| --- | --- |
| 单选题 | 9 |
| 多选题 | 1 |
| 判断题 | 23 |
| 填空题 | 17 |

## 功能

- **一题一张卡片**（部分一）：题干 + 详细答案 / 背诵要点，答案块可单独折叠，也可一键收起全部用于自测。
- **已掌握标记**：每题右上角「✓ 已掌握」，背过就点一下——卡片与右侧导航条对应的题号同时变绿，导航条顶部实时显示已掌握数量（如 4/36），记录存在本机。
- **答案可编辑**：点击答案正文即可修改，自动保存在本机浏览器（`localStorage`），可一键恢复默认。
- **收藏置顶**：题干右侧星标，收藏的题目自动移到页面顶部；取消收藏后回到原章节位置。
- **客观题可直接作答**：选择题点选项、判断题点对错、填空题直接输入，作答后立即判对错并显示正确答案；顶部实时显示「已答 X / 50 · 正确 Y」，可一键重做，进度存在本机。
- **每题单独看答案**：每道客观题下方都有「显示答案 / 收起答案」，可只揭一道，也可用「显示全部答案」整片展开；答案默认收起，方便逐题自测。
- **外侧快速跳转**：宽屏下页面右侧、白色主框之外有一条导航条，01–36 直达任一道简答题，底部「测验」跳到部分二；随滚动高亮当前题。
- **纯题目版**：只列 36 个简答题题干，打开即可开始背；点题目跳回完整版对应位置。
- **搜索与打印**：全文检索（简答题与客观题都可搜）；打印 / 存 PDF 时选项还原为纯文字、答案统一展开显示（不受页面上是否点开影响），部分二自动另起一页（约 21 页）。

编辑内容、收藏与作答记录都存在浏览器本地，不上传任何数据。
